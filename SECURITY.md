# Security and sensitive information

Fairshare does not run a claims backend or need user credentials. Do not publish personal data or secrets in issues.

Use the repository's private vulnerability reporting feature when available. If unavailable, open an issue containing only “Please enable private vulnerability reporting” without the sensitive material, or use the owner's public profile to request a private reporting channel. Do not send a real claimant file as a reproduction.

If you accidentally publish a secret, revoke it with its provider and notify the repository owner through a private channel; deleting a comment or file alone may not remove copies or history. If you publish personal data, seek removal through the relevant platform. No reporting process requires paying a fee or sharing your claim credentials.
